# AngebotPilot

Малък уеб продукт за създаване и управление на професионални оферти от български
майстори и самонаети хора, които работят с немскоезични клиенти.

## Технологии

- Java 17
- Spring Boot 4
- Spring MVC + Thymeleaf
- Spring Data JPA
- H2 за локална разработка
- Maven

## Стартиране

```powershell
mvn spring-boot:run
```

След това отвори `http://localhost:8080`.

Локалната база се пази в папката `data/` и не се добавя в Git.

## Отваряне в IntelliJ IDEA

1. Избери **File → Open**.
2. Отвори папката, в която си запазил проекта.
3. Ако IntelliJ попита, избери **Trust Project** и **Load Maven Project**.

`pom.xml` е главният Maven файл. Всички бъдещи промени по проекта ще бъдат
записвани в същата папка и IntelliJ ще ги вижда автоматично.

## Първи MVP

- управление на клиенти;
- създаване на оферта с няколко позиции;
- автоматично изчисляване на нето, данък и крайна сума;
- проследяване на статуса на офертите.

Следващи стъпки: немски PDF, превод от български, профил на фирмата и изпращане
на офертата по имейл.
